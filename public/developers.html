SC Market API for developers

SC Market is the Star Citizen player marketplace. Its public REST API lets your bot, script or spreadsheet read your shops, listings and stock, follow your orders, move them on and answer offers, with an API token you create in your account settings.

Public API

  • Base URL: https://api.sc-market.space/api/public/v1
  • OpenAPI 3 spec: api/public/v1/openapi.json
  • Interactive reference: api.sc-market.space/docs
  • Guide, step by step: Use the SC Market API with a token

Every request sends the token as a bearer token:

curl -H "Authorization: Bearer scmp_live_…" \
  https://api.sc-market.space/api/public/v1/me

Endpoints cover /me, /shops, /shops/{shop}/listings, /listings/{listingId}/stock, /orders, /orders/{orderId}/status and /offers (accept, decline). Each token is scoped: shop sync, order desk or read only, and the orgs it may act for.
